# @gravity-ui/markdown-plugin-header

[markdown-it](https://github.com/markdown-it/markdown-it) plugin for the header block markup.

```ts
import MarkdownIt from 'markdown-it';
import headerPlugin from '@gravity-ui/markdown-plugin-header';

const md = new MarkdownIt().use(headerPlugin);
```

`headerPlugin` is an empty plugin reserved for the header block markup implementation.
