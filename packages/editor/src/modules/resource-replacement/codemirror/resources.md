# Ресурсы CodeMirror

## Сбор

Только принятая локальная paste/drop-транзакция запускает сбор. Её добавленные
фрагменты разбираются общим настроенным Markdown → PM парсером по отдельности.
Кандидаты всех фрагментов передаются в один resolve. resources задаёт имена узлов,
категории, valueAttribute и необязательный nameAttribute.

Окружение фрагмента намеренно не анализируется: изображение внутри существующего
кодового блока может попасть в запрос, а внешнее определение ссылки недоступно.
Нет CM-обработчиков синтаксиса, source map или сопоставления позиций PM и CM.

## Ожидание

pendingField хранит только идентификаторы, включая промежуток перед resolve.
Undo/redo и переключение режима заблокированы. Текст и ресурсы доступны для правок
и удаления. Лоадеры, atomicRanges и ресурсные декорации отсутствуют.

## Применение

Ответ применяется ко всем совпадениям `(kind, oldValue)` в заново разобранном
актуальном документе. Кодовые узлы/марки и обычные ссылки не заменяются. Сериализация
выполняется только при реальном изменении атрибутов, затем CM получает одну замену между общим префиксом и суффиксом. Ошибка преобразования не приводит к частичной записи.

Сериализация всего документа может изменить форматирование и развернуть ссылочные
конструкции. Результат попадает в обычную историю. Undo может вернуть старые значения,
redo не повторяет resolve. Специальная корректировка истории отсутствует.

## Внешняя история

isCodeMirrorHistoryLocked(state) проверяют до вызова внешнего undo/redo. CM-фильтр
не может отменить уже изменённый Y.Doc. Wiki защищает методы явно переданного в
yCollab менеджера, помечает входящую синхронизацию Transaction.remote и освобождает
свои подписки при уничтожении. Библиотека не импортирует Yjs.
