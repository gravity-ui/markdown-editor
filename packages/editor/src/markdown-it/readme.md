## Markdown-it submodule

### Re-exports Markdown-it plugins:

- [@diplodoc/color-extension](https://github.com/diplodoc-platform/color-extension)
- [markdown-it-ins](https://github.com/markdown-it/markdown-it-ins)
- [markdown-it-mark](https://github.com/markdown-it/markdown-it-mark)
- [markdown-it-sub](https://github.com/markdown-it/markdown-it-sub)

### Plugins of the editor:

- `spoiler` – inline spoiler in the directive syntax `:spoiler[text]`, see [the spoiler docs](../../../../docs/how-to-use-spoiler.md)
