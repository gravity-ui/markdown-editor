# Header

Обложка страницы: фон, заголовок, содержимое, изображение рядом с текстом и до трёх действий.

```md
:::header{format="small" align="center" bg="fill" fill="sky" image="cover.png" text="dark"}

::header-title[Заголовок]{size="1"}

:::header-content

Everything ~~that~~ you [dreamed](https://example.com) of can be brought to life.

:::

::header-image[Иллюстрация](photo.png){side="left" fit="whole"}

:::header-actions

::action[Button](https://example.com){type="button" color="default"}

::action[Button](https://example.com){type="link" color="brand"}

:::

:::
```

## Слоты

Контейнер `:::header{…}` несёт только параметры блока. Текст и изображения задают директивы-слоты внутри него.

| Слот                                         | Назначение                                              |
| -------------------------------------------- | ------------------------------------------------------- |
| `::header-title[Текст]{size}`                | заголовок блока, `size` от `1` до `6`, по умолчанию `1` |
| `:::header-content`                          | содержимое под заголовком                               |
| `::header-image[alt](адрес){side fit focus}` | изображение рядом с текстом                             |
| `:::header-actions`                          | действия, внутри только `::action`                      |

Слоты собираются по имени, порядок в разметке не важен. В HTML превью порядок всегда один: заголовок, содержимое, действия, изображение. Второй слот с тем же именем отбрасывается. Текст вне слотов отбрасывается. Пустой слот в HTML не попадает.

Вложенный контейнер закрывается строкой `:::`. Число двоеточий у вложенных контейнеров может совпадать: `markdown-it-directive` считает уровни по строкам открытия и закрытия.

Заголовок — простой текст: разметка внутри него не разбирается. Обратная косая черта и сущности HTML раскодируются: `\[` даёт `[`, `&amp;` даёт `&`.

В содержимом допустимы абзацы, заголовки, списки и цитаты. Допустимые марки: полужирный, курсив, подчёркивание, зачёркивание, моноширинный текст, код, ссылка, выделение и цвет. Таблицы, блоки кода, изображения, HTML, другие директивы и прочие блоки отбрасываются. У отброшенной марки остаётся текст.

`::action[Текст](адрес){type color}` — кнопка или ссылка. `type`: `button` или `link`, по умолчанию `button`. `color`: `default` или `brand`, по умолчанию `default`. Первые три действия попадают в блок, остальные отбрасываются.

Директивы слотов и `::action` вне своего контейнера не отрисовываются.

## Параметры блока

| Параметр    | Значения                                                    | По умолчанию | Применяется                  |
| ----------- | ----------------------------------------------------------- | ------------ | ---------------------------- |
| `format`    | `small`, `medium`, `large`                                  | `medium`     | всегда                       |
| `align`     | `left`, `center`, `right`                                   | `left`       | всегда                       |
| `vertical`  | `top`, `center`, `bottom`                                   | `center`     | всегда                       |
| `fixed`     | `true`, `false`                                             | `true`       | всегда                       |
| `bg`        | `surface`, `fill`, `shapes`, `gradient`, `mesh`, `pattern`  | `shapes`     | всегда                       |
| `fill`      | цвета палитры таблиц и дополнительные цвета                 | `blue`       | всегда                       |
| `fill2`     | те же цвета                                                 | `purple`     | `gradient`, `mesh`           |
| `direction` | `diagonal`, `right`, `down`                                 | `diagonal`   | `gradient`                   |
| `shapes`    | `diagonal`, `corner`, `edges`, `bottom`, `scatter`          | `diagonal`   | `shapes`, `mesh`             |
| `scale`     | `small`, `medium`, `large`                                  | `medium`     | `pattern`, `layer="tile"`    |
| `image`     | адрес фонового изображения                                  | пусто        | всегда                       |
| `layer`     | `full`, `object`, `tile`                                    | `full`       | задано `image`               |
| `fit`       | `crop`, `whole`                                             | `crop`       | задано `image`, кроме `tile` |
| `focus`     | `center`, `top`, `right`, `bottom`, `left` и четыре угла    | `center`     | задано `image`, кроме `tile` |
| `effect`    | `none`, `darken`, `blur`, `fade`                            | `none`       | `layer="full"`               |
| `text`      | `auto`, `light`, `dark`, `primary`, `brand` и цвета палитры | `auto`       | всегда                       |

Неизвестный параметр отбрасывается, неизвестное значение заменяется значением по умолчанию. `serializeHeaderAttrs` печатает только применимые параметры со значением не по умолчанию; `fill` печатается всегда.

У `::header-image` свои параметры: `side` — `left` или `right`, по умолчанию `right`; `fit` и `focus` — как у фона.

## Фон и изображения

Фон и фоновое изображение находятся на двух независимых слоях. Изображение рядом с текстом — отдельная картинка, она не зависит от фона. В одном блоке допустимы оба изображения.

`focus` задаёт положение кадра при `fit="crop"`. `fit="whole"` показывает изображение целиком. Для `object` и `tile` подходит файл с прозрачным фоном: `fill` виден вокруг изображения.

Адреса изображений принимаются без схемы или со схемами `http:`, `https:`, `blob:` и `data:image/`. Санитайзер `@diplodoc/transform` по умолчанию удаляет `data:`-адреса, поэтому такие изображения видны только при отключённой санитизации или расширенном списке схем.

## Подключение

Превью:

```ts
import {headerDirective} from '@gravity-ui/markdown-editor/extensions/additional/Header/HeaderSpecs/index.js';

transform(markup, {plugins: [headerDirective]});
```

Редактор:

```ts
import {Header} from '@gravity-ui/markdown-editor/extensions/additional/Header/index.js';

builder.use(Header);
```

Блок не входит в пресеты.

## ВИЗИВИГ

Визуального редактирования обложки пока нет. В ВИЗИВИГ блок — один атомарный узел с исходной разметкой. Узел выделяется и удаляется целиком и показывает сообщение и разметку блока. При переключении в разметку узел печатает сохранённый текст без изменений.

Директивы слотов и `::action` вне обложки в ВИЗИВИГ тоже сохраняются как разметка.
