# Header

Обложка страницы: заголовок на оформленном фоне. Монолитный блок — содержимое и оформление
приходят параметрами листовой директивы, вложенных блоков и форматирования внутри нет.

```
::header[Портал команды Вики]{fill="purple" seed="481203"}
```

## Атрибуты

| Атрибут  | Значения                                                                                               | По умолчанию |
| -------- | ------------------------------------------------------------------------------------------------------ | ------------ |
| `format` | `large`, `small`                                                                                       | `large`      |
| `bg`     | `fill`, `shapes`, `gradient`, `mesh`, `pattern`                                                        | `shapes`     |
| `fill`   | `blue`, `indigo`, `purple`, `violet`, `teal`, `green`, `sky`, `amber`, `yellow`, `sand`, `red`, `navy` | `blue`       |
| `fill2`  | те же значения, второй цвет градиента и меша                                                           | `purple`     |
| `image`  | ссылка                                                                                                 | —            |
| `effect` | `none`, `blur`, `dim`, `gradient` — слой поверх изображения                                            | `none`       |
| `text`   | `auto`, `light`, `dark`                                                                                | `auto`       |
| `seed`   | целое                                                                                                  | `0`          |

Неизвестный ключ отбрасывается, неизвестное значение схлопывается в дефолт. `fill` пишется всегда,
остальные дефолты опускаются; атрибут, которого не видно при текущем фоне, не сериализуется.

## Слои

Изображение — нижний слой: фон под ним не виден, но остаётся в разметке и возвращается,
когда изображение убирают. Над изображением лежит `effect`, и он может быть не выбран.

`bg="fill"` — один цвет палитры.
`bg="shapes"` — заливка и размытые фигуры поверх неё.
`bg="gradient"` — переход `fill` → `fill2`.
`bg="mesh"` — цветные размытые фигуры поверх `fill`.
`bg="pattern"` — повторяющийся узор из точек поверх `fill`.

Раскладку фигур даёт детерминированный PRNG от `seed`; `seed="0"` — раскладка из макета.
Анимация — медленный дрейф, `prefers-reduced-motion: reduce` оставляет фигуры статичными.

## Цвет текста

При заливке тон считается по её яркости: контраст с заголовком у любого цвета палитры не ниже 3:1.
Тем же тоном рисуются фигуры и точки узора. Для изображения редактор замеряет яркость загружаемого
файла и пишет `text="light"` или `text="dark"`; значение от автора перебивает замер.
Затемнение и размытие гасят снимок целиком, поэтому оставляют заголовок светлым, а градиент
берёт тон от заливки, на которой лежит заголовок.

## Подключение

```ts
import {Header} from '@gravity-ui/markdown-editor';

builder.use(Header, {fileUploadHandler, headerKey: 'Mod-Alt-h'});
```

`fileUploadHandler` — общий контракт загрузки файлов редактора; без него кнопка загрузки выключена.
Повторное нажатие той же кнопки убирает изображение. В пресеты блок не входит.

## Клавиатура

Enter уводит курсор в абзац под обложкой и создаёт его, если обложка последняя.
Backspace в начале пустой обложки заменяет её абзацем, непустую оставляет на месте.

## Ограничения

Заголовок — простой текст: форматирование и ссылки внутри не поддерживаются.
Подзаголовка и кнопок у блока нет.
