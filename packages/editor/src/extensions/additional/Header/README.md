# Header

Обложка страницы: фон, заголовок, содержимое, изображение рядом с текстом и до трёх действий.

```md
:::header[Заголовок]{h="1" format="small" align="center" bg="cover.png" fill="blue-light" decor="darken"}

Everything ~~that~~ you [dreamed](https://example.com) of can be brought to life.

::image[Иллюстрация](photo.png){side="left" fit="whole"}

::action[Button](https://example.com){type="button" color="blue"}

::action[Button](https://example.com){type="link"}

:::
```

## Разметка

Контейнер `:::header[Заголовок]{…}` несёт заголовок и параметры блока. Всё остальное записывается прямо в теле.

| Часть                                 | Назначение                                        |
| ------------------------------------- | ------------------------------------------------- |
| `[Заголовок]`                         | заголовок блока, без него заголовка нет           |
| `h`                                   | уровень заголовка от `1` до `6`, по умолчанию `1` |
| блоки в теле                          | содержимое под заголовком                         |
| `::image[alt](адрес){side fit focus}` | изображение рядом с текстом                       |
| `::action[Текст](адрес){type color}`  | кнопка или ссылка                                 |

В HTML превью порядок всегда один: заголовок, содержимое, действия, изображение. Порядок директив в теле не важен. Блоки содержимого сохраняют свой порядок. Второе `::image` отбрасывается. Пустая часть в HTML не попадает.

Заголовок — простой текст: разметка внутри него не разбирается. Обратная косая черта и сущности HTML раскодируются: `\[` даёт `[`, `&amp;` даёт `&`.

В содержимом допустимы абзацы, заголовки и цитаты. Допустимые марки: полужирный, курсив, подчёркивание, зачёркивание, моноширинный текст, код, ссылка, выделение и цвет. Эмодзи тоже сохраняются. Маркированные и нумерованные списки, таблицы, блоки кода, горизонтальные линии, изображения, HTML, другие директивы и прочие блоки отбрасываются. У отброшенной марки остаётся текст.

`::action[Текст](адрес){type color}` — кнопка или ссылка. `type`: `button` или `link`, по умолчанию `button`. `color`: `system` или цвет палитры, по умолчанию `system`. Кнопка цвета палитры получает заливку этого цвета, ссылка — цвет текста того же оттенка. У светлого и обычного оттенка один цвет текста, поэтому ссылка светлого оттенка ещё получает его заливку подложкой. Кнопка `system` — контурная: её не спутать с `grey`. Первые три действия попадают в блок, остальные отбрасываются.

`::image` и `::action` учитываются только на верхнем уровне тела: внутри цитаты они отбрасываются. Вне обложки они не отрисовываются.

## Параметры блока

Блок без параметров — ровная поверхность: без заливки, без фигур, с цветом текста редактора.

### Геометрия

| Параметр   | Значения                            | По умолчанию | Смысл                                     |
| ---------- | ----------------------------------- | ------------ | ----------------------------------------- |
| `format`   | `small`, `medium`, `large`          | `medium`     | наименьшая высота: 216, 280, 420 пикселей |
| `edges`    | `rounded`, `bleed`                  | `rounded`    | скруглённые края или без скругления       |
| `fixed`    | `true`, `false`                     | `true`       | фиксированная ширина текстовой колонки    |
| `align`    | `left`, `center`, `right`           | `left`       | горизонтальное выравнивание содержимого   |
| `vertical` | `top`, `center`, `bottom`           | `center`     | вертикальное выравнивание содержимого     |
| `border`   | `none`, `solid`, `dashed`, `dotted` | `none`       | рамка блока оттенком `fill`               |

`bleed` только убирает скругление. Растягивание до краёв страницы задаёт хост.

### Фон

| Параметр | Значения                                                 | По умолчанию | Применяется  |
| -------- | -------------------------------------------------------- | ------------ | ------------ |
| `bg`     | `fill` или адрес фонового изображения                    | `fill`       | всегда       |
| `layout` | `cover`, `object`                                        | `cover`      | в `bg` адрес |
| `fit`    | `crop`, `whole`                                          | `crop`       | в `bg` адрес |
| `focus`  | `center`, `top`, `right`, `bottom`, `left` и четыре угла | `center`     | в `bg` адрес |

`bg="fill"` и пустой `bg` дают заливку. Любое другое значение `bg` — адрес фонового изображения. Опечатка в `fill` тоже становится адресом. Отдельного параметра `image` нет, он отбрасывается как неизвестный.

`cover` — изображение на всю площадь блока. `object` — изображение внутри отступов блока, вокруг виден `fill`.

`fit="crop"` заполняет площадь и обрезает лишнее. `fit="whole"` показывает изображение целиком. `focus` сдвигает кадр только по той оси, где изображение больше площади.

### Дополнительный слой

`decor` рисуется поверх фона: и поверх заливки, и поверх изображения.

| `decor`    | Что рисует                                     | Свои параметры |
| ---------- | ---------------------------------------------- | -------------- |
| `none`     | ничего                                         | —              |
| `darken`   | чёрный слой, 35 % непрозрачности               | —              |
| `lighten`  | белый слой, 45 % непрозрачности                | —              |
| `blur`     | размытие изображения на 12 пикселей            | —              |
| `gradient` | линейный градиент от `fill` к `fill2`          | `direction`    |
| `mesh`     | мягкие размытые пятна цветами `fill2` и `fill` | `shape`        |
| `shapes`   | крупные полупрозрачные фигуры                  | `shape`        |

`direction`: `diagonal`, `right`, `down`, по умолчанию `diagonal`. `shape`: `diagonal`, `corner`, `edges`, `bottom`, `scatter`, по умолчанию `diagonal`.

`blur` размывает только слой изображения, текст остаётся чётким. На заливке без изображения размытие не видно. Поверх изображения `gradient` полупрозрачен, чтобы изображение оставалось видно.

### Цвета

Палитра — та же, что у заливки ячеек таблицы: `grey`, `yellow-light`, `yellow`, `red-light`, `red`, `purple-light`, `purple`, `blue-light`, `blue`, `green-light`, `green`.

| Параметр | Значения                                                     | По умолчанию | Применяется                     |
| -------- | ------------------------------------------------------------ | ------------ | ------------------------------- |
| `fill`   | `system` и цвета палитры                                     | `system`     | всегда                          |
| `fill2`  | цвета палитры                                                | `blue`       | `decor` — `gradient` или `mesh` |
| `text`   | `system`, `grey`, `yellow`, `red`, `purple`, `blue`, `green` | `system`     | всегда                          |

`fill="system"` — заливки нет, виден фон страницы. `text="system"` — цвет текста редактора. Системные значения цвет не задают, поэтому он меняется вместе с темой. Цвета палитры тоже берутся из переменных темы.

Цвет текста берёт переменную `--g-color-text-*`: `grey` — `secondary`, `yellow` — `warning`, `red` — `danger`, `purple` — `utility`, `blue` — `info`, `green` — `positive`. У светлых оттенков палитры таких переменных нет, поэтому в `text` их нет.

Рамка берёт переменную линии того же оттенка `--g-color-line-*`. При `fill="system"` и `fill="grey"` — `--g-color-line-generic`.

### Правила значений

Неизвестный параметр отбрасывается, неизвестное значение заменяется значением по умолчанию. `serializeHeaderAttrs` нужна будущему ВИЗИВИГ: сейчас заглушка печатает исходную разметку. Функция печатает только применимые параметры со значением не по умолчанию в порядке таблиц выше. Уровень `h` печатается первым и только если он не `1`. Адрес изображения печатается в `bg`. Блок без параметров печатается без фигурных скобок.

У `::image` свои параметры: `side` — `left` или `right`, по умолчанию `right`; `fit` и `focus` — как у фона.

## Изображения

Фоновое изображение и изображение рядом с текстом не зависят друг от друга. В одном блоке допустимы оба.

Адреса изображений принимаются без схемы или со схемами `http:`, `https:`, `blob:` и `data:image/`. Санитайзер `@diplodoc/transform` по умолчанию удаляет `data:`-адреса, поэтому такие изображения видны только при отключённой санитизации или расширенном списке схем.

## Подключение

Превью:

```ts
import {headerDirective} from '@gravity-ui/markdown-editor/extensions/additional/Header/HeaderSpecs/index.js';

transform(markup, {plugins: [headerDirective]});
```

Редактор:

```ts
import {Header} from '@gravity-ui/markdown-editor/extensions/additional/Header/index.js';

builder.use(Header);
```

Блок не входит в пресеты.

## ВИЗИВИГ

Визуального редактирования обложки пока нет. В ВИЗИВИГ блок — один атомарный узел с исходной разметкой. Узел выделяется и удаляется целиком и показывает сообщение и разметку блока. При переключении в разметку узел печатает сохранённый текст без изменений.

`::image` и `::action` вне обложки в ВИЗИВИГ тоже сохраняются как разметка.
