# Header

Обложка страницы: заголовок на оформленном фоне. Монолитный блок — содержимое и оформление
приходят параметрами листовой директивы, вложенных блоков и форматирования внутри нет.

```
::header[Портал команды Вики]{fill="purple" seed="481203"}
```

## Атрибуты

| Атрибут  | Значения                                                                                               | По умолчанию | Применяется                       |
| -------- | ------------------------------------------------------------------------------------------------------ | ------------ | --------------------------------- |
| `format` | `large`, `small`                                                                                       | `large`      | всегда                            |
| `bg`     | `fill`, `shapes`, `gradient`, `mesh`, `pattern`                                                        | `shapes`     | всегда                            |
| `fill`   | `blue`, `indigo`, `purple`, `violet`, `teal`, `green`, `sky`, `amber`, `yellow`, `sand`, `red`, `navy` | `blue`       | всегда                            |
| `fill2`  | те же значения, второй цвет градиента и меша                                                           | `purple`     | `bg="gradient"`, `bg="mesh"`      |
| `angle`  | целое, градусы, по модулю 360                                                                          | `163`        | `bg="gradient"`                   |
| `seed`   | целое                                                                                                  | `0`          | `bg="shapes"`, `bg="mesh"`        |
| `step`   | целое, пиксели, от 4 до 512                                                                            | `32`         | `bg="pattern"`, `layer="tile"`    |
| `image`  | ссылка                                                                                                 | —            | всегда                            |
| `layer`  | `cover`, `decor`, `tile`                                                                               | `cover`      | задано `image`                    |
| `fit`    | `cover`, `contain`, `width`, `height`                                                                  | `cover`      | задано `image`, `layer` не `tile` |
| `crop`   | `center`, `top`, `right`, `bottom`, `left`, `top-left`, `top-right`, `bottom-right`, `bottom-left`      | `center`     | задано `image`, `layer` не `tile` |
| `effect` | `none`, `blur`, `dim`, `gradient` — слой поверх изображения                                            | `none`       | задано `image`, `layer="cover"`   |
| `text`   | `auto`, `light`, `dark`                                                                                | `auto`       | всегда                            |

Неизвестный ключ отбрасывается, неизвестное значение схлопывается в дефолт; угол берётся по модулю
оборота, шаг ограничивается диапазоном. `fill` пишется всегда, остальные дефолты опускаются;
неприменимый атрибут остаётся в ноде и не сериализуется.

## Слои

Фон — три слоя снизу вверх: основа, изображение, дополнение поверх изображения.

`bg="fill"` — один цвет палитры.
`bg="shapes"` — заливка и размытые фигуры поверх неё.
`bg="gradient"` — переход `fill` → `fill2` под углом `angle`.
`bg="mesh"` — цветные размытые фигуры поверх `fill`, цвет первой — `fill2`.
`bg="pattern"` — узор из точек с шагом `step` поверх `fill`.

Раскладку фигур даёт детерминированный PRNG от `seed`; `seed="0"` — раскладка из макета.
Анимация — медленный дрейф, `prefers-reduced-motion: reduce` оставляет фигуры статичными.

Место изображения задаёт `layer`.

`layer="cover"` — снимок занимает всю площадь: основа под ним не видна, но остаётся в разметке
и возвращается, когда изображение убирают. Только на этом слое применяется `effect`.
`layer="decor"` — прозрачный файл поверх основы: заливка видна вокруг кадра, поэтому цвет
меняется без замены файла.
`layer="tile"` — файл повторяется с шагом `step` поверх основы.

## Кадрирование

`fit` задаёт масштаб кадра: `cover` — заполнить, `contain` — вписать целиком, `width` — по ширине,
`height` — по высоте. `crop` задаёт, какая часть снимка остаётся в кадре: девять положений от
`top-left` до `bottom-right`. К плитке масштаб и кадр не относятся — её размер задаёт шаг.

Яркость замеряется один раз, при загрузке файла, поэтому после смены `fit` или `crop` тон
заголовка не пересчитывается; его можно задать вручную атрибутом `text`.

## Цвет текста

При заливке тон считается по её яркости: контраст с заголовком у любого цвета палитры не ниже 3:1.
Тем же тоном рисуются фигуры и точки узора. Для снимка на всю площадь редактор замеряет яркость
загружаемого файла и пишет `text="light"` или `text="dark"`; значение от автора перебивает замер.
Под декором и плиткой тон задаёт заливка, поэтому замер не записывается.
Затемнение и размытие гасят снимок целиком, поэтому оставляют заголовок светлым, а градиент
берёт тон от заливки, на которой лежит заголовок.

## Подключение

```ts
import {Header} from '@gravity-ui/markdown-editor';

builder.use(Header, {fileUploadHandler, headerKey: 'Mod-Alt-h'});
```

`fileUploadHandler` — общий контракт загрузки файлов редактора; без него кнопка загрузки выключена.
Повторное нажатие той же кнопки убирает изображение. В пресеты блок не входит.

## Клавиатура

Enter уводит курсор в абзац под обложкой и создаёт его, если обложка последняя.
Backspace в начале пустой обложки заменяет её абзацем, непустую оставляет на месте.

## Ограничения

Заголовок — простой текст: форматирование и ссылки внутри не поддерживаются.
Подзаголовка и кнопок у блока нет.
Изображение занимает либо всю площадь, либо место поверх основы: деления площади на половины нет.
Сторона бокового перехода у `effect="gradient"` и скрима у `effect="blur"` — всегда левая.
